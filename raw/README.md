# Raw Originals

Place read-only original project materials here, such as PDFs and Word documents.

The harness can read these files as explicit context, for example:

```json
{
  "context_files": [
    "raw/design.pdf",
    "raw/requirements.docx"
  ]
}
```

The MVP treats this folder as source material only. It does not write generated or modified documents here.
